## Governing rules

> **RIL:** Freeze the generator, freeze what the representation may know, freeze the coordinates and apparatus, then let the held-out territory exist.

> **RD:** Before asking whether a representation can be learned, verify that the useful representation is actually one reusable object inside the learner target class.

> **Main-line RG:** Freeze the function and semantic geometry first. Adapt the realizer to the function; never adapt the function to the realizer.

> **Program-wide:** Preserve every null and stop at the shallowest unearned transition.
