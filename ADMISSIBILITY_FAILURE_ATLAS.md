## 1. Audit question

The atlas asks:

\[
\boxed{\text{Where does the program most often lose the right to perform the next scientific operation?}}
\]

The operational ordering is:

\[
\boxed{\text{constitution}\rightarrow\text{inhabitation}\rightarrow\text{comparison}\rightarrow\text{optimization}.}
\]

The audit therefore treats comparison itself as typed: a later coordinate is not merely unknown when an earlier object is unconstituted; the later comparison is not yet licensed.

## 2. Retrospective V ladder

| Level | Meaning |
|---|---|
| `V0` | not constituted: no stable semantic/test object yet |
| `V1` | represented/constituted: object or semantic contract exists |
| `V2` | operationally realizable: a non-oracular executable/native path can attempt the object |
| `V3` | demonstrated: the target function/property itself has a bounded witness under frozen conditions |
| `V4` | demonstrated under changed conditions: the same target survives a genuinely changed/held-out condition; seed-only replay does not qualify |

Coding rules:

- `V3` means the **target function/property itself** earned a bounded witness. Merely running an experiment that returns a null does not promote the desired function to V3; that is coded `V2 -> V3 FAIL`.
- `V4` requires the same target to survive a genuinely changed or held-out condition. Seed-only replay does not qualify.
- `OPEN`, `NOT RUN`, `BLOCKED`, `NOT EVALUABLE`, and `FAIL` remain distinct.
- The 54-row inventory uses one representative load-bearing object per repository. It is not an exhaustive enumeration of every historical branch. A second assay table samples the mature executed/frozen lineage more densely.
- Repository counts are descriptive audit counts, not independent statistical samples.

## 4. What recurs

The mature stop events cluster into four recurrent families:

1. **Semantic / operational constitution.** A representation can carry ingredients without natively implementing their consequential semantics. Examples include RG-001 C04/C05, CGP-001 translation, Cerebro composition, Future Sufficiency's invention frontier, SSI binding failures, and XM repair-language insufficiency.
2. **Evidence / provenance admissibility.** An apparatus can run while the evidence source or execution history is not yet licensed. MAGIKARP's built-in generator is deliberately ineligible; AF3-OC distinguishes caller-asserted artifacts from authenticated fresh execution; RIL-003 freezes target provenance before targets exist.
3. **Identifiability / causal-path connection.** The distinction or signal exists, but the path from it to the claimed consequence is not identified. CEA's L signal did not enter `choose_action`; OpenCore repeatedly separated exposure from diagnostic information and calibrated value; CSD/MAB localized attribution failures.
4. **Direct empirical nulls exist, but they are the minority of mature stop events.** CARS Pilot 0, ID1, ASI-0, and OpenCore ARO-001d are examples where a constituted executable object reached a direct effect/calibration test and did not earn the target claim.

The strongest retrospective compression is therefore:

\[
\boxed{\text{representation}\not\Rightarrow\text{native semantics}\not\Rightarrow\text{admissible causal path}\not\Rightarrow\text{consequence}.}
\]

This is **not** proposed as a new primitive or law. It is a compact description of already-preserved failures. The corpus has names for many pieces of the middle path—typing, provenance, authority, support semantics, challenge independence, composition, execution binding, future-operation preservation—but repeatedly loses admissibility somewhere in that path.

### Answer to the atlas question

> **What is the program actually incapable of constituting, over and over again?**

At the mature frontier, the recurring missing object is not “a smarter optimizer.” It is a **native, independently warranted causal path by which a represented distinction or new evidence becomes exactly the consequential change claimed—without the adapter, evaluator, benchmark, or current interface manufacturing the missing semantics or authority.**

That conclusion is narrower than a theory of intelligence. It tells the program what *not* to skip when choosing its next object.
